# Smart Home Automation
Control home appliances (Light, Fan) via Mobile using IoT.

### Components Used
- ESP32 / Arduino UNO
- Relay Module, DHT11 Sensor
- Blynk / Mobile App

### How it works
Mobile -> WiFi -> ESP32 -> Relay -> Appliances ON/OFF
